# Meridian University

## Run locally

Use Node.js 20.9 or later and npm. Before the interview, while online, install dependencies:

```sh
npm install
```

Start the website:

```sh
npm run dev
```

Open http://localhost:3000. If the port is occupied, use the local URL printed in the terminal. Keep the terminal running. On Windows PowerShell, use `npm.cmd` if script execution policy blocks `npm`.

After dependencies are installed, the website runs without internet access. No database, credentials or API keys are needed.

## Assessment

You have 25 minutes. Fix as many issues as you reasonably can, explain your reasoning while working, and demonstrate your fixes in the browser.
